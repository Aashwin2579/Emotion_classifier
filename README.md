# Emotion Classifier

This project classifies text input into emotions like Joy, Anger, Sadness, etc.

## Setup

```bash
pip install -r requirements.txt
```

## Train the Model

```bash
python model/train_model.py
```

## Run the App

```bash
streamlit run app.py
```

## Dataset
Use the "Emotion" dataset from Hugging Face:
https://huggingface.co/datasets/dair-ai/emotion

Place the CSV in `data/emotions.csv`
